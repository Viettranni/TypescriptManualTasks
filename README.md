# Practising my skills in Typescript without the use of AI
- The goal is to code a simple task in 1-3 hours depending on the scope of the task and move on
- All cases will be reviewd with AI after completion to learn more of the different ways to implement

## Running the code
```
npm install
npx ts-node src/[folder]/index.ts
```

## Testing the code in the files that there are tests
```
npx vitest run
```


## Some ideas:
----------------------------------------------------------------------
Music Playlist / Queue Simulator

Create a playlist with songs (name, duration, artist).

Player can add/remove songs, skip, shuffle.

Track current song and play history.

Skills: arrays, objects, classes, methods for manipulation.

----------------------------------------------------------------------
Inventory / Shop Simulator

You have a “store” with items (name, price, quantity).

Player can buy or sell items.

Track player money and inventory.

Optional: restock items randomly.

Skills: arrays of objects, loops, functions, simple economy logic.
----------------------------------------------------------------------     
Personal Budget Tracker

Let a user input expenses and income.

Track totals and remaining balance.

Optional: categorize expenses (food, transport, entertainment).

Extra: display summary with percentages.

Skills: arrays, objects, loops, input/output, basic math.         
----------------------------------------------------------------------              
Contact Book / Address Book

Store contacts: name, phone, email.

Search, add, delete contacts.

Optional: sort contacts alphabetically.

Skills: arrays of objects, loops, string comparison, filtering.
----------------------------------------------------------------------
JSON Data Analyzer

Load a JSON object (like a list of users).

Perform queries: e.g., find oldest user, count by city, average age.

Optional: sort users by name or age.

Skills: arrays, objects, loops, functions, aggregation.              
----------------------------------------------------------------------  
Simple Calendar / Event Planner

Add events to a date.

Show events for a given day or week.

Optional: warn if event overlaps another.

Skills: arrays, objects, date logic, loops, conditionals.
